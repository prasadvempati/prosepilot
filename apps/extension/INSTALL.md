# ProsePilot Extension — Chrome & Edge

## Chrome Installation

1. Open `chrome://extensions/` in Chrome
2. Enable **Developer mode** (top right toggle)
3. Click **Load unpacked**
4. Select the `apps/extension` folder
5. Pin ProsePilot to your toolbar

## Edge Installation

1. Open `edge://extensions/` in Edge
2. Enable **Developer mode** (bottom left toggle)
3. Click **Load unpacked**
4. Select the `apps/extension` folder
5. Pin ProsePilot to your toolbar

## Usage

1. Select text on any webpage
2. Click the purple ProsePilot button in your toolbar
3. Review grammar suggestions
4. Click to apply fixes

## Notes

- Same extension works for both Chrome and Edge
- No modifications needed
- Extension communicates with https://prosepilot.io API
